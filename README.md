# Cadence

A to-do list that scores your day. Do the frog first, build streaks, colour-code work and life areas, and unlock rewards, themes and effects as you go.

Single static page, no build step. Data is stored in the browser (localStorage). Use Settings > Backup to move data between devices.

## Deploy

GitHub Pages: Settings > Pages > Deploy from branch > `main` / root.

Add to iPhone home screen: open in Safari > Share > Add to Home Screen.
